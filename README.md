Цей репозиторій містить вихідний код курсового проєкту з дисципліни **«Об'єктно-орієнтоване програмування»** (Національний аерокосмічний університет «ХАІ», 2026 рік).

**Варіант 6:** Платформа дистанційного навчання.

Проєкт являє собою повноцінну систему управління навчанням (LMS), розроблену на базі архітектурного патерну **MVC (Model-View-Controller)**. Платформа забезпечує взаємодію між викладачами та студентами, підтримує завантаження матеріалів, виконання завдань, автоматичну систему дедлайнів та оцінювання.

---

## ✨ Основний функціонал (за ролями)

### 👨‍🎓 Студент
* **Каталог курсів:** Перегляд публічних та приватних курсів (доступ за паролем).
* **Навчання:** Перегляд теорії, завантаження прикріплених до уроків файлів.
* **Завдання:** Виконання практичних завдань із завантаженням файлів-відповідей.
* **Дедлайни:** Відстеження статусу завдань (в тому числі автоматичний перехід у статус "Прострочено" або "Здано із запізненням").
* **Оцінки:** Перегляд своєї успішності та коментарів від викладачів.

### 👨‍🏫 Вчитель
* **Керування курсами:** Створення власних курсів, налаштування банерів та приватності.
* **Уроки та завдання:** Створення навчальних модулів, додавання файлів, встановлення дедлайнів та максимальних балів за завдання.
* **Учасники:** Схвалення заявок на вступ, виключення або блокування (бан) студентів на своєму курсі.
* **Перевірка робіт:** Перегляд файлів, завантажених студентами, виставлення оцінок та повернення робіт на доопрацювання.

### 🛡️ Адміністратор
* **Повний контроль:** Доступ до редагування та видалення будь-яких курсів, уроків та завдань.
* **Управління користувачами:** Створення нових акаунтів (Вчителів/Студентів), редагування їх профілів, блокування порушників.
* **Обслуговування:** Запуск примусового очищення дискового простору від "сирітських" файлів через вбудований FileManager.

* **База даних:** SQL Server + Entity Framework Core (Code-First approach)

  * Сервіс внутрішніх сповіщень (Notifications).

## 📂 Структура проєкту

Проєкт побудований на строгих принципах ООП (інкапсуляція, успадкування, поліморфізм) з чітким розділенням відповідальності:

* `Controllers/` — Контролери, що відповідають за обробку HTTP-запитів (`CourseController`, `AdminController`, `AccountController` тощо).
* `Models/` — Доменні сутності бази даних (`User`, `Student`, `Teacher`, `Course`, `Task`, `StudentResponse` тощо). Успадкування реалізовано через базовий клас `User`.
* `Models/ViewModels/` — Об'єкти передачі даних (DTO), які використовуються виключно для рендерингу UI та передачі даних у Views.
* `Views/` — Користувацькі інтерфейси (Razor Pages), розділені по теках відповідно до контролерів.
* `Services/` — Додаткові сервіси, такі як `FileManager` (для роботи з фізичними файлами) та `NotificationService`.
* `Data/` — Контекст бази даних `PlatformDbContext` та міграції.
